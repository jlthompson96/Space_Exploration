# 🚀 Space Exploration

A website hosted on GitHub Pages that displays fascinating space data using NASA's publicly available APIs.

## 🌌 Features
- 📡 **Astronomy Picture of the Day (APOD)** – View NASA's daily featured image with descriptions.
- 🌍 **Earth Observation Data** – Access satellite imagery of different Earth locations.
- 🪐 **Planetary Data** – Explore details about planets in our solar system.
- 🚀 **Rover Photos** – View images taken by NASA’s Mars rovers.
- ☀️ **Space Weather** – Get updates on solar activity, geomagnetic storms, and cosmic events.

## 📦 Setup & Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/space-exploration.git
   cd space-exploration
   
2. Install dependencies:
    ```bash
    npm install
    ```
3. Get a free API key from NASA's Developer Portal.
4. Create a .env file in the root directory and add:
     ```bash
    REACT_APP_NASA_API_KEY=your_api_key_here
     ```
6. Start the development server:
    ```bash
    npm start
    ```
7. Open http://localhost:3000 in your browser.
