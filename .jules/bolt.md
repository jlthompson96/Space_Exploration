## 2026-04-26 - Implement Route-Level Code Splitting
**Learning:** The application's main bundle size was unnecessarily large (~449kB) because all top-level route components (`APOD`, `MarsPhotos`, and `NASANews`) and their dependencies (like `axios`) were statically imported in the root routing file `Header.tsx`. This caused users to download the code for all routes on the initial load, regardless of which route they visited first. This is a common performance bottleneck in React applications.
**Action:** Implemented route-level code splitting by replacing static imports with `React.lazy()` and wrapping the `<Routes>` in a `<Suspense>` component. This splits the code into smaller chunks, reducing the initial main bundle size to ~300kB and allowing components to be loaded on-demand. In the future, always verify if routing components are imported statically and convert them to lazy imports to optimize the initial page load time.
